# 성남시 판교 제2·3 테크노밸리 스마트 ITS 프로젝트 (Ongoing)

## 프로젝트 개요

본 프로젝트는 성남시 판교 제2·3 테크노밸리 일대의 **출퇴근 시간대 교통 혼잡 문제**를 해결하기 위해, 실시간 교통 데이터를 기반으로 한 **AI 기반 지능형 교통 시스템(ITS)**을 설계 및 구축한 사례입니다.

특히 대규모 기업 밀집 지역 특성상 **고밀도 단일 시간대 유입**, **이중 병목 교차로 구조**, **보행자-차량 혼재 통행** 문제가 복합적으로 작용함에 따라, 실시간 객체 탐지, 시계열 기반 수요 예측, 강화학습 기반 신호 제어 등 **최신 스마트시티 기술**을 통합 적용하였습니다.

> 💡 주요 적용 구간:
- 제2 테크노밸리 정문(백현역~삼평동 교차로)
- 제3 테크노밸리 서측 진입로(동판교 IC 방향)
- 기업체 출입 시간대 집중 구간(오전 8시~10시 / 오후 5시~7시)

## 주요 기능
- **CCTV/드론 기반 차량 탐지 및 교통량 자동 분석**
    - YOLOv5 + DeepSORT 기반 실시간 다중 객체 추적
    - 혼잡도 Heatmap 시각화 및 동적 대시보드 제공
- **시계열 기반 교통 수요 예측**
    - LSTM 기반으로 요일, 날씨, 이벤트를 포함한 교통량 예측 모델 구현
    - 시간대별 차량 흐름 시뮬레이션 결과 활용하여 적응형 신호 제어에 반영
- **강화학습 기반 교차로 신호 제어 시뮬레이션**
    - DQN 기반 Agent가 SUMO 시뮬레이터와 연동되어 실시간 교통 흐름 최적화
    - '삼평교차로', '이마트 사거리' 등 병목 지점 중심으로 테스트
- **보행자 및 자율주행차 고려 통합 플랫폼 설계**
    - 보행자 검출 기능 통합 → 보행자 신호 대기 최적화 기능 제안
    - 향후 자율주행차 V2I 통신 기반 연계 가능 구조 설계

## 사용 기술
- **AI/분석**: YOLOv5, TensorFlow(LSTM), PyTorch(DQN), Scikit-learn
- **데이터 인프라**: Apache Kafka, PostgreSQL(PostGIS), AWS S3/EC2/Lambda
- **시뮬레이션**: SUMO, TraCI API, SHAP(모델 해석)
- **대시보드/프론트**: Streamlit, Plotly, FastAPI, WebSocket
- **기상/행사 외부 변수 수집**: 기상청 API, 성남시 공공행사 데이터 연동

## 담당 역할
- **교통량 수집 및 실시간 분석 시스템 구축**
    - 판교 주요 교차로에 설치된 CCTV 스트림 수신 → YOLOv5 기반 객체 인식 후 Kafka로 송출
    - 실시간 교통량 추적 및 누적 DB 저장 / 시각화 처리
- **시계열 기반 사고 및 혼잡 예측 모델 개발**
    - LSTM 기반 모델 학습 및 재현성 있는 예측 API 개발
    - 데이터 라벨링 자동화 스크립트 및 학습 스케줄링(Airflow 기반)
- **강화학습 기반 신호 제어 Agent 개발**
    - SUMO 시뮬레이터와 연동된 DQN 에이전트 설계 및 보상 함수 조정
    - 기존 고정 신호 체계 대비 성능 비교 지표 정의 (평균 대기시간, throughput 등)
- **운영자 대시보드 및 알림 시스템 구축**
    - 혼잡도, 예측값, 이상신호 감지를 통합한 모니터링 대시보드 구현
    - 이상 상황 발생 시 관리자 Slack 알림 및 자동 로그 전송

## 성과 및 효과
- 판교 제2·3 테크노밸리 교차로 평균 통과 시간 **17.2% 감소**
- 사고다발 구간 사전 위험도 탐지 정확도 **F1-score 기준 0.91** 달성
- 강화학습 기반 교차로 제어로 인해 **우회전 적체량 22% 감소**, **전체 통과율 1.4배 향상**
- **성남시 스마트도시과 및 한국교통연구원과 협력하여 후속 적용 확대 검토 중**

> ✅ 추후 V2X 기반 자율주행차 통신 연계, 스마트폴 및 AI 횡단보도 통합 제어로 확장 예정
